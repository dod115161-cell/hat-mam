# Hạt Mầm — Ấn bản Mùa Gieo ’26

Website minh họa một cửa hàng hạt giống, kể chuyện bằng cách cuộn trang (scroll storytelling) qua 7 chương: Khu Vườn, Hoa, Rau củ, Thảo mộc, Trái ngọt, Gieo trồng, Gieo ngay.

- Một file `index.html` duy nhất (HTML + CSS + JavaScript thuần, không cần build).
- Hình vẽ bằng SVG sinh từ code, hiệu ứng parallax, vòng sản phẩm 3D, giỏ hàng demo.
- Đây là cửa hàng minh họa, không có giao dịch thật.

## Chạy thử

Mở `index.html` bằng trình duyệt.
